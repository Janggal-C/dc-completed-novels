## 설치 방법 (크롬)

1. 아래 **Assets**에서 `dc-dict-extension.zip`을 받습니다.
2. 압축을 풀어 폴더로 만듭니다. 크롬이 이 폴더를 계속 읽으니 설치 후 **지우거나 옮기지 마세요.**
3. 크롬 주소창에 `chrome://extensions` 를 **직접 입력**해 들어갑니다. (링크로는 안 열립니다)
4. 오른쪽 위 **개발자 모드**를 켭니다.
5. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축 푼 폴더(`manifest.json`이 들어 있는 폴더)를 고릅니다.
6. 디시 장르소설갤에서 줄임말에 마우스를 올리면 원제목 팝업이 뜹니다.

- 제목을 누르면 연재처 작품 페이지, 별점을 누르면 소설넷으로 갑니다.
- 연결이 틀렸으면 팝업의 ⚠️를 눌러 신고해 주세요.
- 확장 아이콘 → 옵션에서 스킨·연재처 우선순위·적용 범위를 바꿀 수 있습니다.

## 업데이트

- **사전은 자동**으로 하루 한 번 갱신됩니다. 따로 할 일 없습니다.
- 확장 기능이 바뀐 새 버전이 나오면: zip을 다시 받아 **같은 폴더에 덮어쓰고**, `chrome://extensions`에서 이 확장의 새로고침(⟳) 버튼을 누릅니다. 설정은 그대로 남습니다.
